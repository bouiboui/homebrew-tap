# Homebrew Tap for Focus

Offline video player, local folder/SD card gallery browser, and lossless multi-cut editor for macOS.

## Install

```bash
brew install --cask bouiboui/tap/focus
```

- **Website:** https://use-focus.com/
- **Requirements:** macOS 14 (Sonoma) or later (Apple Silicon & Intel Universal DMG)
- **Privacy:** 100% offline, telemetry off by default
